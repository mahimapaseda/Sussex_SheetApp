# SheetApp v1.2.1 - Multi-Resolution Windows Desktop Branding

Release **v1.2.1** embeds complete multi-resolution Windows iconography across the entire application interface, desktop shortcuts, taskbar, and Windows Start Menu.

### 🎨 Visual & Branding Updates

- **Multi-Resolution Windows ICO Embed:**
  - Standard multi-layer `.ico` container supporting:
    - **16×16:** Window title bar & system tray
    - **32×32:** Windows Start Menu "Recent" list & Taskbar thumbnail
    - **48×48:** Desktop shortcuts & file association icons
    - **256×256:** File Explorer large & extra-large preview tiles
- **Unpacked Resource Linking:**
  - Added direct fallback to `process.resourcesPath/icon.ico` so the window title bar and taskbar display the custom SheetApp logo instantly on launch without asar extraction lag.
