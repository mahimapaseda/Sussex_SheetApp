### ✨ What's New in v1.1.0

- **Native Windows Desktop Packaging:**
  - Bundled Electron runtime (`v34.2.0`) tuned for low memory footprints.
  - Native Windows `.ico` branding generated directly from Sussex SheetApp brand guidelines.
  - Built-in NSIS installer with customizable destination directory and clean uninstaller support.
  - Zero-installation portable edition (`Portable-x64.exe`) for restricted administrative environments.

- **Agency-Grade "Single-Screen" Architecture:**
  - Zero outer window scrolling (`100dvh` locked layout) with concentric double-bezel styling.
  - Floating island navigation bar, dark/light theme persistence, and pinned batch compliance controls.
  - Multi-branch Google Sheet synchronization and automated anti-ban pacing jitter engine.
